# Subir a GitHub

Esta versión está preparada para evitar el error de archivo demasiado grande.

1. Descomprime este ZIP.
2. Crea un repositorio vacío en GitHub.
3. Sube el contenido de esta carpeta, no el ZIP.
4. Activa GitHub Pages desde Settings → Pages → Deploy from branch → main → /(root).

Para añadir tus renders reales, sustituye los SVG de `assets/` por imágenes JPG/WebP optimizadas.
No subas el PDF original ni imágenes enormes.
